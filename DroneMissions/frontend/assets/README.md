# Drone Missions icon assets

Original, text-free UAV + telemetry/control identity. The SVG master is optimized for responsive UI use; PNG variants and a multi-size Windows ICO are included.

- `drone-missions-mark.svg`: master vector used by login and sidebar.
- `app-icon.svg` / `app-icon-256.png`: app icon artwork.
- `app-icon-192.png`: touch/mobile icon.
- `favicon.svg` / `favicon-32.png`: browser icon.
- `sidebar-mark.png`, `login-mark.png`: size-specific raster exports.
- `drone-missions.ico`: Windows desktop icon.
